# ShadowBox app icon source

The original flattened 1024×1024 artwork is retained as
`ShadowBoxIcon-flat-source.png`. It is not bundled by the app.

The visionOS asset catalog uses two independently populated depth layers:

- `Back`: an opaque dark HUD/ring background generated by removing the glove
  from the flattened source.
- `Middle`: a transparent neon glove extracted from the source.

Both derived layers were produced with the built-in image-generation edit
workflow on 2026-08-08. The glove was first placed on a flat chroma-key field,
then converted to alpha with the bundled `remove_chroma_key.py` helper and
resized to 1024×1024. The background is opaque; the glove layer has transparent
corners. No third-party logo or stock artwork was introduced.

Do not move the flattened source back into an `.imageset`: an unreferenced file
inside the asset catalog produces an asset-compiler warning.
